သုံးနည်း လမ်းညွှန်

Server စတင်ရန် (တစ်ခါပဲ setup)

Node 22+ လိုပါတယ်။ node -v နဲ့ စစ်ပါ။

npm install
npm start

ပြီးရင် browser မှာ http://localhost:3000/dashboard ဖွင့်ပြီး Room ဖန်တီးပါ။

PC — TikTok LIVE Studio

  1. Dashboard မှာ Room ဖန်တီးပြီး Overlay Link ကို copy ယူပါ။
  2. LIVE Studio → Add source → Link မှာ paste ထည့်ပါ (16:9 ဆိုရင် link နောက်မှာ ?ratio=16:9)။
  3. Overlay မှာ “အသံဖွင့်ရန်” ကို တစ်ခါ နှိပ်ပါ။
  4. Go LIVE လုပ်ပြီး Dashboard မှာ username ထည့် “TikTok ချိတ်မယ်” နှိပ်ပါ။

OBS / Streamlabs

  1. Browser source ထည့်ပြီး Overlay Link ကို ထည့်ပါ။
  2. အပေါ်က အဆင့် 3–4 အတိုင်း ဆက်လုပ်ပါ။

ဖုန်းတစ်လုံးတည်း (Termux)

  1. Termux မှာ pkg install nodejs ပြီးရင် node -v က 22+ ဖြစ်ရပါမယ်။
  2. ဒီ folder ထဲမှာ bash start.sh run ပါ (လိုရင် npm install အလိုလို လုပ်ပေးမယ်)။
  3. Browser မှာ http://localhost:3000/control ဖွင့်ပြီး၊ tab နောက်တစ်ခုမှာ http://localhost:3000/overlay ဖွင့်၍ “အသံဖွင့်ရန်” နှိပ်ပါ။
  4. TikTok → + → LIVE → Mobile gaming → Go LIVE။ ပြီးရင် Overlay tab ကို ရှေ့မှာ ထားပါ။
  5. Dashboard မှာ “TikTok ချိတ်မယ်” နှိပ်ပါ။ Control အတွက် ဒုတိယဖုန်း/PC ကနေ http://ဖုန်း-IP:3000/dashboard?room=... ဖွင့်နိုင်ပါတယ် (Wi-Fi တူရမယ်)။

ဂိမ်းကစားနည်း (ကြည့်သူတွေအတွက်)

  • လွန်ဆွဲ: Comment မှာ 1 သို့မဟုတ် 2
  • ဘုရားဖူး: Comment ရေးရင် ခုံနေရာရ၊ Gift ပို့ရင် ပူဇော်မှု
  • ပြိုင်ပွဲများ: Comment / Like နဲ့ ရှေ့တိုး
  • မေးခွန်း: အဖြေမှန်ကို Comment ရေး
  • ဂဏန်း: 1–100 ဂဏန်း Comment ရေး
  • ဒေသပြိုင်: ကိုယ့်ဒေသနာမည် Comment ရေး

ပြဿနာ ဖြေရှင်းရန်

  • TikTok မချိတ်ရင်: LIVE အရင် စတင်ထားလား၊ username မှန်လား (@ မပါ)၊ npm install လုပ်ပြီးလား စစ်ပါ။
  • အသံမထွက်ရင်: Overlay မှာ “အသံဖွင့်ရန်” နှိပ်ထားလား၊ device မှာ မြန်မာ voice ရှိလား စစ်ပါ။
  • ကြည့်သူ မမြင်ရရင်: LIVE က Mobile gaming (screen-share) ဖြစ်ရပါမယ်၊ camera LIVE ဆိုရင် overlay မပေါ်ပါ။
  • Dashboard ကို public internet မှာ မဖွင့်ပါနဲ့ — ကိုယ့် Wi-Fi / ကိုယ့်စက်မှာပဲ သုံးပါ။
