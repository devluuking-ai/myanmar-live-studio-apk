ဖုန်းနဲ့ LIVE လွှင့်နည်း

1. Hub မှာ Studio တစ်ခု ရွေးပါ။
2. Scene / Audio / Rules မှာ ကြိုက်သလို ပြင်ပါ။ Auto-Demo နဲ့ အရင် စမ်းပါ။
3. TikTok → LIVE → Mobile gaming → Go LIVE အရင် စပါ။
4. Go Live tab မှာ username ထည့်ပြီး TikTok LIVE ချိတ်မယ် နှိပ်ပါ (password မလိုပါ)။
5. Fullscreen Broadcast စပြီး Show ကို ရှေ့မှာ ထားပါ။ Controls ကို နှစ်ချက် နှိပ်ရင် ပွင့်တယ်။
