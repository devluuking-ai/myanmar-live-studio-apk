TikTok LIVE · ကြည့်သူတွေ ကိုယ်တိုင် ကစားတဲ့ ဂိမ်း

ကြည့်သူတွေ ကိုယ်တိုင် ကစားတဲ့ TikTok LIVE

Comment၊ Like၊ Gift နဲ့ ဂိမ်းထဲ ဝင်ကစားကြမယ်။ Open source — ကိုယ့်စက်မှာ ကိုယ်တိုင် run ရတယ်၊ Google login မလို၊ license မလို၊ watermark မပါ၊ နေ့စဉ် အချိန်ကန့်သတ်ချက် မရှိပါ။

Dashboard ဖွင့်မယ်Demo ကြည့်မယ်သုံးနည်း

အသုံးပြုပုံ — 3 ဆင့်ပဲ

1. Dashboard ဝင်

TikTok username ထည့်ပြီး Room ဖန်တီးပါ။

2. Link ကို တစ်ခါပဲ ထည့်

Overlay link ကို TikTok LIVE Studio (Add source → Link) သို့မဟုတ် OBS Browser source ထဲ ထည့်ပါ။ ဖုန်းဆိုရင် Mobile gaming နဲ့ ဖွင့်ပါ။

3. Go LIVE

Live စပြီး Dashboard မှာ TikTok ချိတ်ပါ။ Comment၊ Like၊ Gift အားလုံး ဂိမ်းထဲ တန်းပေါ်မယ်။

ဘာတွေ ပါလဲ

ဝင်လာသူ = ဇာတ်ကောင်

ကြည့်သူတိုင်း နာမည်နဲ့ ပုံပါတဲ့ ဇာတ်ကောင် ဖြစ်လာမယ်။

Gift = လှုပ်ရှားမှု

Gift တိုင်း အသင်းကို အားဖြည့်၊ ဘုရားမှာ ပူဇော်၊ Boss ကို ထိချက်ပေး။

မြန်မာ အသံ

နာမည်ခေါ် ကြိုဆို၊ Gift ကို ကျေးဇူးတင် (device မြန်မာ voice လိုတယ်)။

ကုသိုလ်ရှင် ထိပ်ဆုံး

Gift အများဆုံး 5 ယောက် ပြမယ်။

ပန်းတိုင် bar

ပန်းတိုင် ပြည့်ရင် အခမ်းအနား။

Like / Follow

Like 1,000 တိုင်း အခမ်းအနား၊ Follow ကို ကျေးဇူးတင်။

မောင်း၊ လက်ခုပ်၊ အောင်ပွဲ — တစ်ချက်နှိပ်။

နေ့ / ည

ဘုရား scene တွေ အချိန်အလိုက် အလိုလို ပြောင်းတယ်။

ဂိမ်း 17 မျိုး

လွန်ဆွဲ၊ ဘုရားဖူး၊ အပြေးပြိုင်၊ မေးခွန်း၊ Boss၊ သင်္ကြန်၊ ဒေသပြိုင် စတာတွေ — live မပြတ်ဘဲ ပြောင်းလို့ရတယ်။

မေးလေ့ရှိတာ

TikTok password ပေးရမလား?

မပေးရပါဘူး။ Username နဲ့ public live ကိုပဲ ဖတ်တာပါ။

ဖုန်းနဲ့ပဲ live လွှင့်လို့ရလား?

ရပါတယ်။ Termux မှာ server run ပြီး overlay ကို TikTok Mobile gaming နဲ့ လွှင့်ပါ။ လမ်းညွှန်

TikTok official လား?

မဟုတ်ပါ။ TikTok နဲ့ မသက်ဆိုင်ပါ။ ကိုယ်တိုင် ကင်မရာ/အသံနဲ့ ရှိနေပြီး လုံခြုံ mode ဖွင့်ထားပါ။
